# Мини-CRM «Объекты и задачи»

Небольшая система для строительной компании: руководитель ставит задачи по объектам (стройкам), исполнители выполняют их и отдают на проверку.

**Открыть сайт:** https://crm-rueen.vercel.app/ или https://crm-seven-gamma-93.vercel.app

## Как войти

На сайте есть только вход по email и паролю (регистрация отключена специально — пользователей создаёт администратор).

| Кто | Email | Пароль |
|------|-------|--------|
| Руководитель (постановщик) | manager@test.com | 11111111 |
| Исполнитель | worker1@test.com | 11111111 |
| Исполнитель | worker2@test.com | 11111111 |

Просто скопируйте любой email из таблицы, вставьте на странице входа и введите пароль `11111111`.

## Что кто может

**Руководитель** — главная роль, видит всё:

- создаёт объекты (стройки) и задачи по ним;
- назначает исполнителя на задачу;
- редактирует и удаляет объекты и задачи;
- когда исполнитель сдал работу — принимает её или возвращает на доработку (с обязательным комментарием);
- видит все объекты и все задачи всех исполнителей.

**Исполнитель** — работает только со своим:

- видит только свои задачи и только те объекты, где есть его задачи. Чужие задачи и чужие объекты он не увидит даже пытаясь открыть их напрямую;
- берёт задачу в работу, когда готов;
- когда выполнил — отправляет её на проверку руководителю;
- если руководитель вернул задачу на доработку, снова берёт её в работу и переделывает;
- задачи создавать, удалять и менять статусы не может — только эти действия.

## Как работает задача

У задачи есть статусы, и они идут строго по кругу:

**Новая → В работе → На проверке → Принята** (или **На доработке → снова В работе**)

По каждой задаче ведётся история: кто, когда сменил статус и с каким комментарием. История видна обеим ролям и защищена от подделки — изменить или удалить записи нельзя.

## Как посмотреть всё самому

1. Откройте сайт по ссылке выше.
2. Войдите как руководитель: `manager@test.com` / `11111111`.
3. Откройте любой объект — увидите его задачи и их статусы.
4. Зайдите в задачу — увидите данные, историю и доступные кнопки.
5. Выйдите (кнопка выхода в интерфейсе) и войдите как исполнитель: `worker1@test.com` / `11111111`.
6. Сравните: исполнитель видит меньше объектов и не может принимать задачи — это не «спрятанные кнопки», а защита на уровне базы данных. Даже если отправить запрос напрямую в базу в обход сайта, чужие данные не отдадутся и запрещённый переход статуса не пройдёт.
